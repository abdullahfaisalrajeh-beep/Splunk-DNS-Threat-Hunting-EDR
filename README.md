# 🛡️ Splunk Security & Threat Hunting Project
> منظومة متكاملة لمراقبة ورصد التهديدات السيبرانية باستخدام Splunk SIEM.

---

## 📌 1. English Description / نظرة عامة بالإنجليزية

An advanced security project designed to enhance visibility, detection, and incident response capabilities using **Splunk SIEM**, network traffic analysis, and endpoint telemetry.

### **Key Features:**
* **DNS Traffic Analysis:** Detect malicious queries, DNS tunneling, and anomalous network patterns.
* **VPN Monitoring:** Track remote access sessions, abnormal login locations, and potential unauthorized access.
* **Endpoint Detection & Response (EDR):** Integrate security alerts with automated remediation and containment workflows.
* **Threat Hunting Queries:** A curated collection of advanced Splunk Processing Language (SPL) queries for proactive threat hunting.

### **Tech Stack:**
* **SIEM:** Splunk
* **Security Domains:** DNS Traffic Analysis, VPN Logs, EDR
* **Query Language:** Splunk Processing Language (SPL)

## 📌 2. Arabic Description / الوصف بالعربية

مشروع أمني متقدم يهدف إلى تعزيز قدرات الرصد، الاكتشاف، والاستجابة للتهديدات السيبرانية باستخدام منصة **Splunk SIEM** وتقنيات تحليل الشبكات ونقاط النهاية.

### **مميزات المشروع:**
* **تحليل حركة مرور DNS:** رصد الاستعلامات الخبيثة، هجمات الـ DNS Tunneling، والأنماط غير الطبيعية.
* **مراقبة شبكات VPN:** تتبع جلسات الاتصال عن بُعد، رصد محاولات الدخول المشبوهة أو من مواقع جغرافية غير معتادة.
* **الاستجابة لنقاط النهاية (EDR):** ربط التنبيهات الأمنية بإجراءات استجابة واحتواء آلية.
* **استعلامات مخصصة (Threat Hunting):** مجموعة من استعلامات Splunk (SPL) المتقدمة لكشف التهديدات الخفية.

### **التقنيات المستخدمة:**
* **منصة إدارة الأحداث الأمنية:** Splunk SIEM
* **التخصصات الأمنية:** تحليل حركة DNS، سجلات VPN، الاستجابة لنقاط النهاية (EDR)
* **لغة الاستعلام:** Splunk Processing Language (SPL)
